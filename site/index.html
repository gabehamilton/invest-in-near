Limits and open questions

What this page cannot settle yet, and what would settle each item.

  • Slashing unverified · affects H6, c14

    As far as I can tell NEAR does not slash validator stake today, but I have not confirmed it in the protocol spec or the nearcore source. If slashing exists, liquid staking carries a loss path that none of the yield figures include.

    Would resolve it: Cite the nearcore code path or the Nomicon section that governs slashing, pinned to a commit.

  • LiNEAR instant-exit depth not measured · affects H6, c14

    Meta Pool's instant-unstake pool holds 75,887 NEAR, read from its contract. LiNEAR's equivalent was not measured, so the same-day liquidity row of the sweep checklist is marked partial.

    Would resolve it: Read LiNEAR's instant-unstake liquidity and fee from its contract at the same height as the Meta Pool read.

  • Binance and Bybit options, not checkable from the US not checkable · affects H8, c15

    Binance's options API and Bybit's public endpoints refuse requests from US addresses, so the venue table marks them not checked rather than no. Unchecked venues: 2.

    Would resolve it: A venue check from a non-US network, with each venue's HTTP status.

  • Purpose of the treasury outflow unverified

    The treasury.near balance, column treasury_near in data/raw/rpc/history_samples.csv, dropped sharply in one quarter this year. I could not find a published purpose. Supply growth is unaffected; sell pressure might not be.

    Would resolve it: A treasury report or an on-chain trace that names where the NEAR went.

  • Origin of the quoted staking rate unverified · affects H3, c01

    The hypothesis quotes a staking rate without saying where it came from. The ledger tests the claim against the measured trailing-year liquid staking yield, 4.13%, and shows both.

    Would resolve it: Name the dashboard and the date the quoted rate came from.

  • BigQuery freshness depends on BigQuery · affects H10, c05, c16

    Exact burn figures need the public NEAR BigQuery dataset, whose latest block date is 2026-11-10; where it has no data the figure is labelled sampled or upper bound.

    Would resolve it: The BigQuery dataset keeping pace with the chain (the data page shows its lag in days).

  • Permission to publish Intents Explorer aggregates open · affects c06

    The NEAR Intents Explorer comparison needs partner access and written permission to publish under its terms. It is not included, so the Intents volume chart rests on DefiLlama alone.

    Would resolve it: Partner access and a written answer from NEAR Intents.

  • Bank of England money series open · affects c21

    Sterling money here is the wide aggregate the Bank publishes as M4; the narrower version that excludes intermediate financial companies is the closer match for other currencies' broad money, but its series code is not confirmed.

    Would resolve it: The confirmed Bank of England series code for the narrower aggregate.
